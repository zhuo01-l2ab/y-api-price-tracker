# Y-API 価格表 — 書き写さず、再計算する

[English](README.md) · [简体中文](README.zh.md) · **日本語** · [한국어](README.ko.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Português](README.pt.md)

> **開示：** 私は Y-API の開発に関わっているため、これは当事者が当事者のファイルを読むツールです。出力のすべては <https://y-api.bestvirtualgoods.com/pricing.json> 由来です。このファイルは公開されており API キーも不要です。スクリプトを実行して、出力とソースを自分で突き合わせてください。

依存関係なし、API キー不要のスクリプト 1 本です。Y-API が公開している価格ファイルを読み、**現金価格**入りの [table.md](table.md) を生成します。現金価格とは実際にカードから引き落とされる金額であり、他社の定価と比較できる唯一の数字です。

## なぜ必要か

Y-API の価格は**クレジット**建てで、現在は $1 の入金につき $20 のクレジットです。クレジットは残高から引かれる額であり、カードから引かれる額ではありません。クレジットだけの表はどのモデルも 20 倍高く見せますし、「20 で割る」とハードコードした表は、期間限定レートが終わった日に静かに壊れます。このスクリプトは価格と**同じファイル**からレートを読み出します。

## 実行方法

```bash
node price-table.mjs > table.md                            # 公開ファイルを取得
PRICE_JSON=./pricing.json node price-table.mjs             # 保存済みのコピーをオフラインで描画
```

Node 18+ が必要です（グローバル `fetch` を使用）。このリポジトリの `table.md` は毎週月曜に GitHub Action が再生成し、**変更があったときだけコミット**します。つまりコミット履歴そのものが価格変更のログです。

## スクリプトが守る 2 つのルール

どちらかでも破ると、出自であるサイトと静かに食い違う表ができます。

1. **現金価格は写さず再計算する。** ファイルには `cash_price` が公開されていますが、スクリプトは `credit_price / top_up.quota_rate` を再計算し、**一致しなければ大声で失敗**します。古いレートや手で書き換えた数字が表に紛れ込むことはありません。
2. **`vendor_cheaper_on_cached_input` は単独では出力しない。** このフラグは「ベンダーのキャッシュ入力料率が当方の現金価格を下回る」、つまりキャッシュ多用のワークロードでは当方が割高だという意味です。ただし一部の行は `historical-price`（過去の料金表に基づく）を併せ持ち、Y-API サイトはそれらを「キャッシュで負けている」件数から意図的に除外しています。**フラグだけを出せば、読者は誤った件数を持ち帰ります。** だから 2 列セットです。

## 出力の読み方

- **カタログ** — 全モデル、クレジットと現金、100 万トークンあたり、価格順。
- **ベンダー自身の定価との比較** — 検証して出典を明記できた 11 モデルについて、倍率・キャッシュフラグ・caveats・検証日・ベンダーページへのリンクを掲載。残り 4 モデルは「検証して引用できるベンダー価格なし」と明示されます。ファイルは推測せず、そのまま書きます。

`× ours` は「ベンダーは当方の現金価格の何倍か」です。倍率が大きいのは**当方が安い**という意味で、高いという意味ではありません。

## 対象範囲（正直に）

- 表の鮮度はソースファイル次第です。ヘッダにソースの `synced_at` と描画日を出しています。両方が古ければ、ここに新しい情報はありません。
- これは**ひとつ**のゲートウェイの価格を描画するだけです。プロバイダー横断の比較もしませんし、他社の価格履歴も追いません。
- 価格は動きます。入金レートは期間限定で終了日は未発表です。この表から判断するなら、`table.md` のコピーではなくソースから再計算してください。
