# Y-API 가격표 — 복사하지 않고 다시 계산한다

[English](README.md) · [简体中文](README.zh.md) · [日本語](README.ja.md) · **한국어** · [Español](README.es.md) · [Deutsch](README.de.md) · [Português](README.pt.md)

> **이해관계 공개:** 저는 Y-API를 만들고 있으므로 이 도구는 당사자가 당사자 파일을 읽는 것입니다. 출력되는 모든 값은 <https://y-api.bestvirtualgoods.com/pricing.json>에서 옵니다. 이 파일은 공개되어 있고 API 키도 필요 없습니다. 스크립트를 직접 실행해 출력과 원본을 대조해 보세요.

의존성 없는 스크립트 하나, API 키 불필요. Y-API가 공개한 가격 파일을 읽어 **현금 가격**이 담긴 [table.md](table.md)를 만듭니다. 현금 가격이란 실제로 카드에서 빠져나가는 금액이며, 다른 공급자의 정가와 비교할 수 있는 유일한 숫자입니다.

## 왜 필요한가

Y-API의 가격은 **크레딧** 단위입니다. 현재 $1을 결제하면 $20의 크레딧이 생깁니다. 크레딧은 잔액에서 차감되는 금액이고, 카드에서 차감되는 금액이 아닙니다. 크레딧만 적힌 표는 모든 모델을 20배 비싸게 보이게 하고, "20으로 나누기"를 하드코딩한 표는 프로모션 레이트가 끝나는 날 조용히 틀린 표가 됩니다. 이 스크립트는 가격과 **같은 파일**에서 레이트를 읽습니다.

## 실행

```bash
node price-table.mjs > table.md                            # 공개 파일을 가져옴
PRICE_JSON=./pricing.json node price-table.mjs             # 저장해 둔 사본을 오프라인에서 렌더링
```

Node 18+ 필요(전역 `fetch` 사용). 이 저장소의 `table.md`는 매주 월요일 GitHub Action이 다시 만들고, **변경이 있을 때만 커밋**합니다. 즉 커밋 히스토리 자체가 가격 변동 로그입니다.

## 스크립트가 지키는 두 가지 규칙

둘 중 하나라도 깨면, 출처 사이트와 조용히 어긋나는 표가 됩니다.

1. **현금 가격은 복사하지 않고 다시 계산한다.** 파일에는 `cash_price`가 공개되어 있지만, 스크립트는 `credit_price / top_up.quota_rate`를 다시 계산하고 **둘이 다르면 크게 실패**합니다. 낡은 레이트나 손으로 고친 숫자가 표에 섞여 들어갈 수 없습니다.
2. **`vendor_cheaper_on_cached_input`은 절대 단독으로 출력하지 않는다.** 이 플래그는 "벤더의 캐시 입력 요율이 우리 현금 가격보다 낮다", 즉 캐시가 많은 워크로드에서는 우리가 더 비싸다는 뜻입니다. 그런데 일부 행은 `historical-price`(과거 요금표 기준)를 함께 달고 있고, Y-API 사이트는 그 행들을 "캐시에서 지는 경우" 집계에서 의도적으로 제외합니다. **플래그만 출력하면 독자는 잘못된 개수를 가져갑니다.** 그래서 두 열을 함께 제공합니다.

## 출력 읽는 법

- **카탈로그** — 모든 모델, 크레딧과 현금, 100만 토큰당, 가격순.
- **벤더 자체 정가와의 비교** — 검증하고 출처를 밝힐 수 있었던 11개 모델에 대해 배수, 캐시 플래그, caveats, 검증 날짜, 벤더 페이지 링크를 함께 표시. 나머지 4개는 "검증해 인용할 수 있는 벤더 가격 없음"으로 명시됩니다. 파일은 추정하지 않고 그대로 씁니다.

`× ours`는 "벤더가 우리 현금 가격의 몇 배를 받는가"입니다. 배수가 크다는 것은 **우리가 더 싸다**는 뜻이며, 더 비싸다는 뜻이 아닙니다.

## 범위, 있는 그대로

- 표의 신선도는 원본 파일에 달려 있습니다. 머리글에 원본의 `synced_at`과 렌더링 날짜를 적어 둡니다. 둘 다 오래됐다면 여기엔 새 정보가 없습니다.
- 이것은 게이트웨이 **하나**의 가격만 렌더링합니다. 공급자 간 비교도, 타사의 가격 이력 추적도 하지 않습니다.
- 가격은 변하고, 충전 레이트는 종료일이 발표되지 않은 한정 레이트입니다. 이 표로 판단하려면 `table.md` 사본이 아니라 원본에서 다시 계산하세요.
